# HFA Subtitles Auto Transcription

HFA Subtitles Auto Transcription is a tool designed to facilitate the creation of subtitles for the **Harvard Film Archive**. This project automates transcription and translation, making it easier for researchers, archivists, and film enthusiasts to generate and edit subtitles efficiently.

## Features

- **Automatic Transcription**: Converts spoken language in films into text.
- **Subtitle Formatting**: Outputs subtitles in .srt format
- **Efficient Workflow**: Reduces manual effort in subtitling historical and archival footage.
